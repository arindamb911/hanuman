# 🕉️ Hanuman Tribute Page

A simple tribute webpage dedicated to **Lord Hanuman**, created using HTML.

## 🌟 Features

* Clean and simple design
* Dedicated to Lord Hanuman
* Includes audio of *Hanuman Chalisa* sung by Shankar Mahadevan

## 🛠️ Built With

* HTML
* CSS

## 🎯 Purpose

This project was created as part of my learning journey in web development and to practice building structured webpages.
